# FAQ

**A balance alert showed up as a credit.** Fixed in 1.13.0: balance-only messages are ignored.

**A transfer added the other person's account to my list.** Fixed in 1.13.0: the payee's account number is no longer taken as yours. Remove an old one from view in Accounts › edit › Remove from view.

**Uber or other card spends show a code like UBERIND13513699.** Recognised from 1.13.0 and filed under Transport › Cabs.

**USD spends are missing from totals.** Add a rate under Settings › Forex rates.

**Outlook says it needs an app password but I can't find one.** Turn on two-step verification first; see [[Email and statements]].
